# Civic Opposition of India Portal

A modern, scalable web application built for the Civic Opposition of India NGO to promote transparency, accountability, and civic engagement.

## 🚀 Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Shadcn UI
- **Backend**: Supabase (PostgreSQL, Auth, Storage)
- **Icons**: Lucide React
- **Deployment**: Vercel (recommended)

## 🔧 Setup Instructions

### 1. Configure Supabase

1. Go to [Supabase Dashboard](https://app.supabase.com)
2. Get your project URL and anon key from Settings → API
3. Open `.env.local` and paste your credentials:

```env
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key_here
```

### 2. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.

### 3. Set Up Database Tables

Run this SQL in your Supabase SQL Editor:

```sql
-- 1. PROFILES (Extends Supabase Auth)
create table public.profiles (
  id uuid references auth.users not null primary key,
  full_name text,
  role text default 'member',
  phone text,
  avatar_url text
);

-- 2. ACTIVITIES (Daily Feed)
create table public.activities (
  id bigint generated by default as identity primary key,
  created_at timestamptz default now(),
  title text not null,
  content text,
  location text,
  image_url text,
  author_id uuid references public.profiles(id),
  tags text[]
);

-- 3. ARCHIVES (Documents)
create table public.archives (
  id bigint generated by default as identity primary key,
  title text not null,
  category text,
  file_url text not null,
  year int
);

-- 4. CAMPAIGNS (Petitions)
create table public.campaigns (
  id bigint generated by default as identity primary key,
  title text not null,
  description text,
  goal_count int default 1000,
  current_count int default 0,
  status text default 'active'
);

create table public.signatures (
  id bigint generated by default as identity primary key,
  campaign_id bigint references public.campaigns(id),
  user_id uuid references public.profiles(id),
  comment text
);

-- 5. DONATIONS
create table public.donations (
  id bigint generated by default as identity primary key,
  amount numeric not null,
  payment_id text,
  donor_name text,
  status text default 'pending',
  created_at timestamptz default now()
);
```

## 🔒 Security Notes

- Never commit `.env.local` to version control
- Use Row Level Security (RLS) in Supabase
- Implement role-based access control for admin routes
- Validate all user inputs on the server side
